TL;DR Go straight to the Windows 11 End-of-Life Audit On October 13th, 2026, version 24H2 of Windows 11 Home and Pro edition will go end of life. Any devices running this version won’t receive any more security updates, patches, or technical support from Microsoft. Make sure to update any devices running Windows 11 within your organization.
